# Display the current working directory
pwd

# List files
ls -la

# Check internet connectivity
ping -c 4 openai.com

# Display DNS information
nslookup openai.com

# Display routing information
traceroute openai.com

# Query WHOIS 
whois openai.com

nslookup openai.com: looks up the IP address associated with the domain name openai.com. It uses the Domain Name System (DNS) to translate a human-readable domain name into an IP address that computers use to communicate.

traceroute openai.com: shows the path that network packets take from your computer to openai.com. It displays each router (called a hop) the packets pass through and how long each hop takes to respond.
