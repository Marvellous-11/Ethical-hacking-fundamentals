# Shodan

Shodan is a search engine for Internet-connected devices.

Unlike Google, which indexes websites, Shodan indexes devices such as:

- Servers
- Routers
- Cameras
- Firewalls
- Industrial Control Systems (ICS)

## Why Security Professionals Use Shodan

- Asset discovery
- Exposure assessment
- Security research
- Infrastructure visibility

## Ethical Note

Shodan should be used responsibly and only for legitimate security purposes.
