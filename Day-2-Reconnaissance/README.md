# Day 3 - Information Gathering (Reconnaissance)

## Overview

Reconnaissance, also known as Footprinting, is the first phase of Ethical Hacking. During this phase, an ethical hacker gathers information about a target before attempting any security testing.

The objective is to understand the target's infrastructure, technologies, services, domains and publicly available information.
